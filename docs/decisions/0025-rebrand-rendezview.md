# 0025 Rebrand to Rendezview

Status: accepted

## Decision

The product name is Rendezview, replacing "RDV Garage". "RDV" stays the term for a meet, cruise or private event and is still said R-D-V. The map style "RDV Night" keeps its name.

## Consequences

- Specs say Rendezview wherever they said RDV Garage.
- The repositories keep their current names (`rdv-garage`, `rdvgarage-spec`) until the owner renames them.
- Store listings, the app display name, bundle identifiers, the landing page and the legal text still carry the old name in the code repository and must be updated there.
