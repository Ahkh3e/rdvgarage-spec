# Release 0.0.2

Plans and places on top of the live map: drop a pin or an RDV, find a place by name, and open it in Waze.

## In scope

| Module | Scope in 0.0.2 | Spec |
|---|---|---|
| Maps handoff | Directions on a place, pin or RDV opens Waze by default; Me, Maps app switches to Apple Maps or Google Maps; web fallback; only the coordinates leave the app | features/maps-handoff.md |
| Places | Search addresses and named places such as stores through a server function; long press or Drop pin for crew-visible pins that expire after 24 hours; Nearby by category read from the map tiles; straight-line distance from your own position on the device | features/places.md, decision 0024 |
| RDVs | Meet, cruise and private event with place, time, crews and arrival radius; Going, Maybe, Can't; private event place hidden until Going or Maybe; arrival by location (live member on the device, or I'm here); local reminders; Plans list, crew detail list and map ring pin; Go live for this RDV prompt that opens the sheet with its crews chosen; Meets attended in Me, Stats | features/rdvs.md, stats.md |

Supporting changes: the product is renamed Rendezview in the specs (decision 0025), `docs/data-model.md` and `docs/api.md` gain the `places` and `rdvs` schemas, and `docs/disclaimers.md` gains the line for places and RDVs.

## Out of scope

Remote push (#33), app icon and splash (#36), the map tiles hosting decision (#37), Android build and scenarios (#38), install on an iPhone with a free Apple ID (#39), revisiting the 3D cars (#40), streaks, car profiles, galleries, convoy, minigames, and moving free services to paid ones (#41). Those issues are in the 0.0.4 milestone, except #41.

## Status: ready for dev testing

Built, reviewed and merged in https://github.com/Ahkh3e/rdv-garage (tag `v0.0.2`). A hosted development project exists (Supabase, Canada Central) with every migration and the five Edge Functions deployed, and signup is invite-only with test-mode auto-confirm.

Verified on two iOS simulators against each other: both phones live, Directions with no Waze installed, the Maps app setting, an RDV with Going, arrival by live position and by I'm here, a private event, cancel, crew detail, Stats, the Go live offer from an RDV, and tapping a pin and an RDV pin to see their notes.

Known limits for dev testing:
- Nothing has run on a physical phone: installed-app detection for Waze and Google Maps, long press on the real map, real GPS for I'm here, reminders firing, and live arrival with the app in the background.
- The tile category names for car wash and EV charging came from memory and may list nothing.
- Search uses the public Photon service, which is free and has no guarantee (decision 0024), and finds only what OpenStreetMap lists.
- A change to an RDV reaches a closed app only through remote push, which is not built.
- The app text, display name and bundle id still carry the old name in the code repository.
- Email is not set up; the hosted development project auto-confirms accounts (decision 0014).
- The map package still knows about RDV pins, `list_rdvs` recomputes counts on every poll, and the pin pulse rerenders about four times a second; these are listed under Follow-ups in https://github.com/Ahkh3e/rdv-garage/pull/14.
