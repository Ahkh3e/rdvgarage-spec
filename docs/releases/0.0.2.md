# Release 0.0.2

Plans and places on top of the live map: drop a pin or an RDV, find a place by name, and open it in Waze.

## In scope

| Module | Scope in 0.0.2 | Spec |
|---|---|---|
| Maps handoff | Directions on a place, pin or RDV opens a maps app, Waze by default | features/maps-handoff.md |
| Places | Search by name or address, crew-visible pins, Nearby by category | features/places.md, decision 0024 |
| RDVs | Meets, cruises and private events with RSVP, arrival by location, reminders, Plans, and Meets attended in Me, Stats | features/rdvs.md, features/stats.md |

Supporting changes: the product is renamed Rendezview in the specs (decision 0025), `docs/data-model.md` and `docs/api.md` gain the `places` and `rdvs` schemas, and `docs/disclaimers.md` gains the line for places and RDVs.

## Out of scope

- Moved to the 0.0.4 milestone: remote push (#33), app icon and splash (#36), the map tiles hosting decision (#37), Android build and scenarios (#38), install on an iPhone with a free Apple ID (#39), and revisiting the 3D cars (#40).
- Not in a milestone: moving free services to paid ones (#41).
- Later phases in `docs/roadmap.md` and not started: streaks, car profiles, galleries, convoy and minigames.

## Status: ready for dev testing

Built, reviewed and merged in https://github.com/Ahkh3e/rdv-garage (tag `v0.0.2`), with the module list in `apps/mobile/src/modules.ts` there. A hosted development project exists (Supabase, Canada Central) with the migrations and Edge Functions of this release deployed. Signup is invite-only with test-mode auto-confirm (decision 0014).

Verified on two iOS simulators against each other: both phones live, Directions with no Waze installed, the Maps app setting, an RDV with Going, arrival by live position and by I'm here, a private event, cancel, crew detail, Stats, the Go live offer from an RDV, and tapping a pin and an RDV pin to see their notes.

Known limits for dev testing, with the issue that tracks each:
- Nothing has run on a physical phone, including Waze and Google Maps detection, long press, real GPS, reminders firing, live arrival in the background, and the Nearby car wash and EV charging categories, whose tile names were not checked (#49).
- RDV reminders need the notification permission, which is asked only at first Go live (#50).
- The app text, display name and bundle id still carry the old name in the code repository (#48).
- A change to an RDV reaches a closed app only through remote push (#33).
- Search finds only what OpenStreetMap lists, and runs on a self-hosted Photon (decision 0024, #41).
- Email is not set up; the hosted development project auto-confirms accounts.
- Implementation follow-ups are listed in https://github.com/Ahkh3e/rdv-garage/pull/14.
